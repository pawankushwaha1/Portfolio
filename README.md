# Pawan K. Kushwaha — Portfolio

Personal portfolio showcasing product design, physical prototyping, and digital experiences.

## ✨ Features
- **Interactive UI**: Lens cursor magnifier, smooth parallax background engine, audio player.
- **Admin Panel (`admin.html`)**: In-browser visual content management system (CMS) with live preview, preset backgrounds, project and experience editing, and auto-sync.
- **Static Hosting**: Ready for deployment via GitHub Pages or any static web host.

## 🚀 Tech Stack
- HTML5, CSS3 (Custom Properties & Modern Layouts)
- Vanilla JavaScript (Zero External Dependencies)
